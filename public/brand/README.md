# Aset brand NutriVerse

Logo resmi yang aktif:

- `nutriverse-app-icon-200.png`: avatar resmi 1:1 berukuran 200×200 untuk aplikasi, sidebar, login, admin, Moments, dan badge ekspor.

Aset lama tetap disimpan sebagai cadangan dan referensi implementasi:

- `nutriverse-logo.svg`: logo horizontal untuk sidebar, landing, login, dan admin.
- `nutriverse-mark.svg`: ikon persegi untuk mobile, favicon, dan ruang sempit.
- `nutriverse-watermark.svg`: watermark terang untuk ekspor media sosial.

Komponen `BrandLogo` menyusun ikon resmi dan wordmark secara responsif. Untuk produksi cetak atau ekspor beresolusi tinggi, ganti sumber raster ini dengan SVG/PNG transparan resmi dari tim tanpa mengubah proporsi mark.
